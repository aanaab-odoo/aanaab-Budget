🌍 Publish this link for everyone

"Save and reconnect" above only affects your own browser. Use this instead so every department head gets the Web App URL automatically — no setup screen, ever, on any device. You only need this when you first set the tool up, or whenever you create a brand-new Apps Script deployment (a "New version" on the same deployment never changes the URL, so you won't need to redo this for that).

Stays saved only in your own browser, and is used only to save one small file (config.json) to your GitHub repo. Create one at github.com → Settings (your profile, not the repo) → Developer settings → Personal access tokens → Fine-grained tokens → give it "Contents: Read and write" access to the aanaab-Budget repo only.
